Title: WebGPU Fundamentals in Rust

A set of articles to help learn WebGPU using [Rust](https://www.rust-lang.org/) and [wgpu](https://wgpu.rs/). This is a Rust adaptation of [webgpufundamentals.org](https://webgpufundamentals.org/) — same lessons, same WGSL, but all the application code is Rust, runs natively via wgpu, and runs live in these pages compiled to WebAssembly.
